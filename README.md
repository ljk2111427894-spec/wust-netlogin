# 🎓 校园网自动认证与断线重连守护系统 (CampusNet Auto-Login)

针对武科大校园网认证网关（**`59.68.177.9`**）深度定制的全自动登录与断线重连守护工具。集成现代图形化控制面板（GUI）、纯后台守护（Daemon）以及一键批处理启动，支持 **WiFi 无线连接**、**宿舍网线宽带拨号（PPPoE）**、**网线直连 Web 认证** 与 **智能混合自适应** 等多种上网接入方式。

---

## ✨ 核心特性

1. **多接入模式全覆盖**：
   - 📻 **WiFi 自动连接 + 网页认证**：监测无线网络状态，若断开自动重新连接指定 SSID（默认 `WUST-WiFi6`，支持一键扫描 WiFi 并双击直接选择填入），连上后毫秒级完成 Portal 认证。
   - 🔌 **网线宽带拨号（PPPoE / 宽带连接）**：宿舍有线拨号场景专用，集成 Windows `rasdial` 核心，支持一键生成系统拨号项，掉线即刻自动重拨。
   - 🌐 **网线直连 + 网页认证**：适用于教学区/实验室有线网插线直接通过 Web Portal 认证。
   - ⚡ **智能混合自适应模式**：自动检测有线网线是否插好，插上网线优先使用有线（Web/拨号），拔掉网线自动回退至无线 WiFi。

2. **双层高可用连通性检测**：
   - **底层直连探测**：跳过系统代理/VPN/Clash，通过国内高可用 204 探针（华为、小米）及百度进行实时网络活性心跳。
   - **Portal 网关状态感知**：实时通过 `59.68.177.9` 服务端接口获取当前账号登录状态、物理 MAC、分配 IP、已用流量统计及后端二次拨号状态。

3. **任务栏可见守护（拒绝偷偷隐式后台）**：
   - **开机自启最小化**：电脑开机启动时以最小化窗口形态常驻在 **Windows 任务栏**（而非无界面的隐式后台进程），用户随时可以点击任务栏图标展开面板查看实时网络、延迟与流量监控。
   - **一键最小化**：控制面板提供 **【🗕 最小化到任务栏】** 快捷按钮，支持开启守护时自动最小化。

4. **窗口尺寸与位置记忆**：
   - 支持自动记忆用户调整后的窗口长宽、屏幕位置以及全屏最大化状态。关闭重新打开后 100% 还原用户设定的大小，无需反复调整。

5. **现代化交互面板**：
   - 原生支持高分屏 DPI 自适应缩放，界面清晰不发虚。
   - 实时呈现账号名、IP、已用流量、登录时长、网络延迟。
   - 包含实时彩色运行日志流、WiFi 一键扫描双击选择、网络全面诊断等实用工具。

## 🚀 快速使用方法

### 方式一：直接双击图形界面启动（推荐）
- 双击文件夹中的 **`CampusNetLogin.exe`**（或 **`Start_CampusNet.bat`**）。
- 在弹出的界面中填写您的**学号/账号**和**密码**。
- 选择您的连接模式（如默认无线用户选择 `WiFi无线 + 网页认证`，宿舍插网线拨号选择 `网线宽带拨号 PPPoE`）。
- 点击 **【⚡ 立即登录认证】** 或 **【🛡️ 开启自动守护 (重连)】**。
- 点击 **【🗕 最小化到任务栏】**，程序将收缩在任务栏静默守护，点击任务栏图标随时查看实时监控。

### 方式二：双击快速守护脚本
- 双击 **`Daemon_CampusNet.bat`**。
- 将直接启动程序并最小化到任务栏中静默守护网络。

### 方式三：命令行参数
```bash
# 启动 GUI 交互界面
python main.py

# 启动 GUI 界面并直接最小化到任务栏 (推荐开机启动使用)
python main.py --minimized

# 启动纯后台控制台监控守护
python main.py --daemon

# 单次执行登录认证
python main.py --login

# 查询当前账号在线状态与流量信息
python main.py --status

# 注销退出当前账号
python main.py --logout
```

## ⚙️ 配置文件说明 (`config.json`)

系统配置保存在当前目录下的 `config.json` 中，可直接通过界面修改，也可以手动编辑：

```json
{
  "auth_url": "http://59.68.177.9",
  "username": "你的校园网学号",
  "password": "你的校园网密码",
  "carrier": "",
  "connect_mode": "wifi_web",
  "wifi_ssid": "WUST-WiFi6",
  "pppoe_name": "宽带连接",
  "check_interval": 15,
  "auto_reconnect": true,
  "auto_start": true,
  "auto_daemon_on_start": true,
  "minimize_on_daemon": false,
  "window_geometry": "860x720",
  "window_is_maximized": false
}
```

### 字段释义：
- `auth_url`: 校园网 Web 认证服务器地址，固定为 `http://59.68.177.9`。
- `username`: 校园网账号（如学号）。
- `password`: 校园网密码。
- `carrier`: 运营商后缀（默认校园网留空，中国电信为 `@telecom`，移动为 `@cmcc`，联通为 `@unicom`）。
- `connect_mode`:
  - `"wifi_web"`: WiFi 网页认证
  - `"cable_pppoe"`: 网线 PPPoE 宽带拨号
  - `"cable_web"`: 网线直连 Web 认证
  - `"auto"`: 智能自适应
- `wifi_ssid`: 无线网络名称（默认 `WUST-WiFi6`）。
- `pppoe_name`: Windows 宽带拨号连接名称（默认 `宽带连接`）。
- `check_interval`: 心跳检测周期（单位：秒，建议 10~30 秒）。
- `auto_reconnect`: 断线后是否自动重连 (`true`/`false`)。
- `auto_start`: 是否随系统开机自启 (`true`/`false`)。
- `auto_daemon_on_start`: 启动后是否自动开始守护监控 (`true`/`false`)。
- `minimize_on_daemon`: 开启守护时是否自动最小化至任务栏。
- `window_geometry`: 上次关闭时的窗口分辨率与屏幕位置。
- `window_is_maximized`: 是否处于最大化状态。

## 🛠️ 常见问题与排错

### 1. 扫描 WiFi 时如何快速填入？
点击【🔍扫描】按钮，在弹出的可用 WiFi 列表中，**直接鼠标双击**目标网络（如 `WUST-WiFi6`）或选中后按回车，即可瞬间自动填入输入框并关闭弹窗。

### 2. 电脑重启后程序怎么运行？
勾选【开机自启】后，电脑每次重启将**自动以最小化窗口的形式常驻在屏幕底部的任务栏中**。您随时能看到它的运行图标，点击图标即能展开查看实时日志、延迟、流量及当前在线设备信息，绝不会在后台暗中运行。

### 3. 打开了 Clash / VPN 代理，会影响自动登录吗？
**不会**。本程序针对校园网内部通信（`59.68.177.9`）及外网检测探针做了直连配置（Direct Connection），自动绕过系统代理与本地代理端口，断网时依然可以正常与认证网关通信。
